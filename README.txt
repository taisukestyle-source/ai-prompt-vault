# AI Prompt Vault（初期版）

## できること
- サムネイル画像とタイトルで一覧表示
- タイトル・プロンプト検索
- メインプロンプト／ネガティブプロンプト保存・コピー
- 追加画像の複数登録
- お気に入り、編集、削除
- JSONバックアップと復元
- IndexedDBによる端末内保存
- PWAとしてホーム画面に追加、Service Workerによるオフライン起動

## iPhoneで使うための導入
このフォルダをHTTPS対応の静的Webホスティングに配置してください。PWAのインストールとService Workerは、通常HTTPS配信が必要です（localhostを除く）。
1. フォルダ内のファイル一式を静的ホスティングへアップロード。
2. 発行されたHTTPS URLをiPhoneのSafariで開く。
3. 共有ボタン →「ホーム画面に追加」→「Webアプリとして開く」を有効にして追加。
4. 初回にページを開いた後、オフライン起動できることを確認。

## データについて
- 画像・テキストはIndexedDBに保存し、アプリ提供サーバーへアップロードしません。
- ブラウザのWebサイトデータ消去、端末故障、ブラウザ環境の変更などに備え、定期的に右上の「↥」からバックアップを作成してください。
- 復元は右上の「↧」からJSONバックアップを選択します。復元は既存データと統合します。
- 「枚数無制限」はアプリ側で枚数上限を設定しない意味です。実際の上限は端末の空き容量・ブラウザの保存容量に依存します。
- iOS Safariでの動作を想定しています。初回導入・更新にはネット接続が必要です。

## 開発メモ
依存ライブラリなしのHTML/CSS/JavaScriptです。index.html、app.js、manifest.webmanifest、sw.js、icon-192.png と icon-512.png を含む全ファイルを同じ階層に配置してください。
